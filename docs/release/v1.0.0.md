# BrewLite v1.0.0 – Release notes

Ngày phát hành: điền ngày gắn tag `v1.0.0` · Môi trường: production (Vercel + Render)

## Tính năng (MVP)

- Menu đồ uống, chi tiết món, chọn size S/M/L và topping, giá cập nhật ngay (FR-01, FR-02)
- Giỏ hàng lưu trên trình duyệt (FR-03)
- Đăng ký, đăng nhập JWT (FR-04)
- Đặt đơn, backend tự tính lại giá từ CSDL (FR-05)
- Thanh toán **mô phỏng** Ví điện tử / Thẻ, idempotent; thẻ đuôi `0002` để thử nhánh lỗi (FR-06, FR-07)
- Xác nhận đơn, theo dõi trạng thái, lịch sử đơn (FR-08, FR-09)
- Màn hình quầy `/staff`: PAID → PREPARING → READY → COMPLETED theo state machine (FR-10)
- Mã khuyến mãi, điểm thưởng 1 điểm / 10.000đ (FR-11, FR-12)
- Giữ chỗ nguyên liệu, không bán quá tồn kho (FR-13)
- Hủy đơn, tự hủy đơn chờ thanh toán quá 15 phút (FR-14)

## Vận hành

- `GET /health` trả trạng thái DB và commit SHA đang chạy
- CI: Install → Lint → Unit test → Build, integration test PostgreSQL, E2E Playwright (Pixel 7)
- CD: image GHCR gắn tag SHA → deploy Render + Vercel → smoke test → rollback về `stable` khi lỗi

## Sửa lỗi so với Assignment 1

- Backend tin đơn giá client gửi lên khi tạo đơn; nay tính lại theo BR-01 (phát hiện bởi integration test AC-04)
- `.env.example` không còn chứa giá trị bí mật thật

## Hạn chế đã biết

- Chưa có PWA manifest (FR-15, Could)
- Render gói miễn phí ngủ sau 15 phút không truy cập; lần gọi đầu mất khoảng 30–60 giây
- Cổng thanh toán là mô phỏng, không kết nối cổng thật

- Integration test (PostgreSQL): 12 test pass · E2E Playwright: 3 kịch bản pass
